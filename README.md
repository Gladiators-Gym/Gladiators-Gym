Gladiators Gym — النسخة المخففة لتسريع تحميل الموقع

محتويات الحزمة:
- index.html: صفحة الموقع ولوحة الإدارة كما في الملف المرفوع.
- gym.json: نفس بيانات الموقع بعد تحويل الصور المضمّنة إلى مسارات ملفات منفصلة.
- media/: الصور المستخرجة من gym.json. لا تحذف هذا المجلد ولا تغيّر أسماء الصور.

طريقة الرفع إلى GitHub:
1) افتح مستودع الموقع.
2) ارفع/استبدل index.html و gym.json في نفس المجلد الرئيسي.
3) ارفع مجلد media بكامل محتوياته إلى المجلد الرئيسي (بحيث تصبح المسارات مثل media/image-01.jpg).
4) انتظر اكتمال GitHub Pages ثم افتح الموقع مع تحديث قوي Ctrl+F5.

مهم:
- لم تُحذف أي صورة أو عرض أو بيانات من gym.json؛ تم فقط استبدال كل data:image... بمسار ملف مستقل.
- ارفع المجلد media كاملًا مع الملفين. إذا رفعت gym.json وحده فلن تظهر الصور.
- الصور الجديدة التي تُضاف لاحقًا من لوحة الإدارة قد تُضمَّن داخل gym.json مجددًا؛ بعد إضافة صور جديدة، يلزم فصلها كملفات مستقلة بالطريقة نفسها أو تحديث طريقة الرفع.
